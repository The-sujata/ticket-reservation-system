# 🎫 Ticket Reservation System

A web-based ticket booking system built using PHP, where users can search, book, and manage ticket reservations easily.

## 🛠️ Technologies Used
- PHP
- HTML
- CSS
- MySQL

## ✨ Features
- User registration and login
- Search and book tickets
- View booking details
- Admin panel to manage reservations

## 🚀 How to Run This Project
1. Download or clone this repository
2. Set up a local server (like XAMPP or WAMP)
3. Import the database file into MySQL/phpMyAdmin
4. Place the project folder inside the `htdocs` folder
5. Open the project in your browser using `localhost/ticket-reservation-system`
